Browser API da 2Captcha

Prova de conceito da issue 298. O código está em hinale/scraper-api-test. O guia oficial é a Browser API.

O script usa a Puppeteer pelo pacote puppeteer-core. O Chrome não roda na máquina local: a 2Captcha sobe a sessão e o Puppeteer só conecta nela.

O que a API faz

A Browser API entrega um Chrome na nuvem. A gestão fica em https://api.2captcha.com. O browser fica em ws://…@cb.2captcha.com:9222. A mesma chave da conta 2Captcha vale para esta API e para a Scraper API. Ela vai no campo key.

A Scraper API abre uma URL e devolve o HTML dessa página. A Browser API deixa o script clicar, preencher e esperar o JavaScript. Por isso a consulta da FIPE, que depende do formulário, cabe aqui.

O fluxo desta POC:

  1. GET /browser/accounts reaproveita a conta chamada scraper-api-test. Se ela não existir, POST /browser/accounts cria uma, com proxyMode: "none".
  2. POST /browser/connection devolve o connectionUri. A sessão só começa quando o Puppeteer conecta.
  3. puppeteer.connect({ browserWSEndpoint }) abre a página e liga Captcha.setAutoSolve.
  4. O script escolhe mês, marca, modelo e ano e lê o preço médio.

O que é necessário

  • Conta 2Captcha e a API key. Se BROWSER_API_KEY estiver vazia, o script usa SCRAPER_API_KEY.
  • Node.js com puppeteer-core. Não é preciso instalar o Chrome local.
  • Um proxy de saída. Sem proxy, a conta cai no IPv6 gratuito da 2Captcha. Esse modo é temporário na documentação e a FIPE bloqueia esse IP.

O modelo está em .env.example. O .env não é versionado. A URL de conexão e a senha do proxy não entram no log.

BROWSER_API_BASE_URL=https://api.2captcha.com
BROWSER_API_KEY=
BROWSER_PROXY_TYPE=http
BROWSER_PROXY_HOST=
BROWSER_PROXY_PORT=
BROWSER_PROXY_LOGIN=
BROWSER_PROXY_PASSWORD=

Com host e porta preenchidos, o script manda customProxy em POST /browser/connection. Esse proxy vale só para aquela conexão e tem prioridade sobre o proxy salvo na conta.

Como rodar

npm install
node src/browser-fipe.mjs \
  --marca Renault \
  --modelo "Sandero Authentique Hi-Flex 1.0 16V" \
  --ano 2011

Marca, modelo e ano são parâmetros. Cada palavra do modelo precisa aparecer no texto da opção da FIPE. Sandero authentique 1.0 16V sozinho combina com duas opções, Hi-Flex e Hi-Power. O comando acima usa Hi-Flex, que é a versão com ano 2011 Flex.

A consulta é feita duas vezes, em setembro/2025 e setembro/2026. O stdout é só o JSON pedido na issue, com os valores em centavos:

{
  "sep2025": 2553500,
  "sep2026": 2513600
}

R$ 25.535,00 vira 2553500. R$ 25.136,00 vira 2513600. Esses dois números foram lidos no formulário oficial, fora da Browser API, para cravar o seletor e a conversão. A execução pela Browser API ainda não devolveu esse JSON. O motivo está na seção seguinte.

Trecho que conecta e preenche

A conta e a URL saem da API HTTP. O Puppeteer só recebe o WebSocket.

const connection = await fetch("https://api.2captcha.com/browser/connection", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    key: apiKey,
    accountId: account.id
  })
});
const { connectionUri } = await connection.json();

const browser = await puppeteer.connect({ browserWSEndpoint: connectionUri });
const page = await browser.newPage();
const session = await page.createCDPSession();
await session.send("Captcha.setAutoSolve", {
  autoSolve: true,
  options: [{ type: "*" }]
});
await page.goto("https://veiculos.fipe.org.br/#carro");

No site, o modelo está no select #selectAnoModelocarro e o ano em #selectAnocarro. O script dispara o change do jQuery da própria página, que é o que carrega a lista seguinte, e clica em #buttonPesquisarcarro. O preço sai da tabela #resultadoConsultacarroFiltros.

O que a execução de 27/10/2026 devolveu

A conexão com cb.2captcha.com funcionou e o Captcha.setAutoSolve foi aceito. A página da FIPE abriu com o título Attention Required! | Cloudflare e o texto Sorry, you have been blocked.

A chave usada não tem proxy 2Captcha (proxy_account_not_created). A conta ficou em proxyMode: "none", no IPv6 gratuito. O Cloudflare bloqueia esse IP antes do formulário. Não houve evento Captcha.detected: a tela é um bloqueio, não um desafio para resolver.

O script agora reconhece essa tela e encerra na hora, em vez de esperar o formulário. Para obter o JSON, preencha BROWSER_PROXY_HOST e BROWSER_PROXY_PORT com um proxy que a FIPE aceite e rode de novo.

Limites usados

  • Uma conexão CDP por perfil. O script fecha o browser no fim para soltar o perfil.
  • A sessão na nuvem dura no máximo 30 minutos.
  • A listagem de contas vem em data como objeto, não como array. O script lê Object.values.
